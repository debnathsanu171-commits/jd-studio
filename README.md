# JD Studio site (static, GitHub Pages)
Edit src/config.json (brand, contacts, UPI, youtubeIds, localVideos) then run `python3 build.py` → index.html, sitemap.xml, robots.txt.
YouTube: put video IDs in "youtubeIds"; when any are set they replace the local MP4 fallbacks in the Videos section.
Live: https://debnathsanu171-commits.github.io/jd-studio/
